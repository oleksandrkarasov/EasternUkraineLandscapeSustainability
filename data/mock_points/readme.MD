# Synthetic point tables

Ten zipped shapefiles that stand in for the social-media records, which cannot be
shared. They were made by `Python_A0_make_mock_training_points.py` from public
covariates and a random spatial field; no post, user or date enters them. Upload
each file as an Earth Engine table asset named like the file (README, step 2).
The numbers obtained with these points are not those of the paper.
