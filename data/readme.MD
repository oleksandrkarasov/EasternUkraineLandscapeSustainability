# Data shipped with the code

- `upload_to_GEE/SUSTD_aoi.zip`: study area (Luhansk, Donetsk and Kharkiv oblasts), zipped shapefile.
- `upload_to_GEE/SUSTD_ordlo.zip`: area occupied before 24 February 2022 (ORDLO), zipped shapefile.
- `h3_hexagons_res6.gpkg`: H3 resolution-6 hexagons used for the comparison with war events.
- `mock_points/`: ten synthetic point tables that stand in for the social-media records.

Not shipped, prepared by the user (README, step 1): `war_events4326.gpkg`,
`upload_to_GEE/SUSTD_war_events.zip` and `ESA_WorldCover_2021_Ukraine_AOI.tif`.
